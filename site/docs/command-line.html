Command Line

bx — run, transpile, compile, emit

usage: bx run FILE
       bx transpile FILE -o OUT.c
       bx emit-c FILE
       bx compile FILE -o OUT [--target T]
       bx asm FILE -o OUT.s [--target T]
       bx raw FILE -o OUT.bin [--target T]
       bx targets
       bx version
       [-t|--time] [--keep-c] [--keep-comments] [-D NAME] [-U NAME]

Options may appear anywhere.

Modes

| mode | what it does | |---|---| | run FILE | Interpret FILE and print output. Nothing written to disk. | | transpile FILE -o OUT.c | Emit a self-contained C program to OUT.c. The BX source and runtime are embedded; compiling OUT.c produces a native executable that behaves identically to bx run. | | emit-c FILE | Print the generated C to stdout (for piping). | | compile FILE -o OUT [--target T] | Build a native executable. Default target is native. | | asm FILE -o OUT.s [--target T] | Emit assembly instead of a binary. | | raw FILE -o OUT.bin [--target T] | Flat binary, no ELF wrapper — for bootloaders or disk images. | | targets | List all known compile targets and their compilers. | | version | Print bx version and compare with VERSION file. |

Flags

| flag | effect | |---|---| | -o OUT | Output file (required for transpile, compile, asm, raw). | | --target NAME | Compiler/triple for compile, asm, raw. Default: native. | | --keep-c | Keep the intermediate generated C file in /tmp. | | -t, --time | Print elapsed time to stderr: bx: MODE FILE took X.XXXXXX s. | | --keep-comments | Accepted for compatibility; not yet acted on. | | -D NAME, -U NAME | Accepted for compatibility; not yet acted on. |

Targets

bx targets prints the table:

| target | compiler | |---|---| | native | cc | | x86_64 | x86_64-linux-gnu-gcc | | i386 / i686 | i686-linux-gnu-gcc | | aarch64 | aarch64-linux-gnu-gcc | | armv7 / arm | arm-linux-gnueabihf-gcc | | riscv64 | riscv64-linux-gnu-gcc | | riscv32 | riscv32-linux-gnu-gcc | | mips / mipsel / mips64 | mips*-linux-gnu-gcc | | powerpc / ppc64 / ppc64le | powerpc*-linux-gnu-gcc | | s390x | s390x-linux-gnu-gcc | | sparc64 | sparc64-linux-gnu-gcc | | loongarch64 | loongarch64-linux-gnu-gcc |

Cross targets require the matching cross-compiler installed. ./setup.sh --cross attempts to install them.

No freestanding/Multiboot/UEFI targets yet. The kernel under src/ is a hand-written ELF32 Multiboot1 image built by make kernel with src/kernel.ld, not via bx compile.

Makefile wrapper

make            # build ./bx
make smoke      # run, transpile, compile, asm, raw a test program
make features   # string and file builtin tests
make gfx-tests  # gfx library tests
make gfx2-tests # BXVG tests
make math-tests # math/logic tests
make friendly-tests # friendly language tests
make snd-tests  # sound tests
make bxe-tests  # BxE tests
make ui-tests   # UI tests
make packagetests # package manager tests (isolated cache)
make run-example            # run examples/hello.bx (EXAMPLE= overrides)
make compile-example        # compile with $(TARGET), default native
make asm-example            # emit assembly
make raw-example            # emit flat binary
make targets                # list compile targets
make os                     # compile os/os.bx -> .build/boxed-os
make run-os                 # build and run boxed-os
make run-os-vm              # run boxed-os in QEMU
make run-os-gfx             # run boxed-os with graphics in QEMU
make kernel                 # build .build/kernel.elf
make verify-kernel          # boot kernel under QEMU, check BOXEDLANG-OK
make install [PREFIX=]      # install to /usr/local/bin (or PREFIX)
make clean                  # remove bx, .build/, *.out

setup.sh one-shots: ./setup.sh (build + smoke), --install, --user (~/.local/bin), --cross (cross-compilers).
