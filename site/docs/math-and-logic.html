Math and Logic

math — Integer arithmetic

math performs integer arithmetic. The signature is:

math|OUT|A|B|OP

| field | meaning | |---|---| | OUT | box to receive the result | | A | first operand (number or box) | | B | second operand (number or box) | | OP | operator: +, -, *, x, /, % |

All values are integers. Division truncates toward zero; modulo by zero yields 0. An unknown operator prints a warning to stderr and stores 0 in OUT.

box a|20
box b|7

math add|$a|$b|+
say The sum is $add

math diff|$a|$b|-
say The difference is $diff

math prod|$a|$b|*
say The product is $prod

math quot|$a|$b|/
say The quotient is $quot

math rem|$a|$b|%
say The remainder is $rem

Output:

The sum is 27
The difference is 13
The product is 140
The quotient is 2
The remainder is 6

test — Conditional branch to a box

test evaluates a comparison and writes one of two values to a box.

test|OUT|LEFT|OP|RIGHT|IF_TRUE|IF_FALSE

| OP | meaning | |---|---| | == | equal (numeric if both operands parse as numbers, else string) | | != | not equal | | > | greater than (numeric only) | | < | less than (numeric only) | | >= | greater or equal (numeric only) | | <= | less or equal (numeric only) | | === | strict equal (always string) | | !== | strict not equal (always string) |

If IF_TRUE/IF_FALSE are omitted they default to 1/0. Non-numeric operands with ordering ops (> < >= <=) evaluate false.

test result|10|>|5|YES|NO
say $result

test is_eq|hello|==|world|same|different
say $is_eq

test is_num|5|===|"5"|strict|loose
say $is_num

Output:

YES
different
loose

if — Execute a nested command when true

if evaluates the same condition syntax as test and runs a single nested command when true. When false it falls through silently.

if|LEFT|OP|RIGHT|NESTED_COMMAND

The nested command is any valid line (it can be jump, mark, say, math, another if, ...).

box score|100
if $score|>|50|say You passed!

Output: You passed!

Combining with marks for control flow:

if $loggedin|==|2|jump|loggedin|m

If the condition is false, if does nothing and execution continues on the next line.

jumpif — Jump when true

jumpif is if + jump combined, and is the preferred way to branch:

jumpif|LEFT|OP|RIGHT|TARGET|m

The |m suffix means TARGET is a mark name. Without it TARGET is a 1-based line number.

box i|0
premark loop
math i|$i|1|+
say $i
jumpif $i|<|3|loop|m
say done
end

Output:

1
2
3
done

Truthiness

Any non-empty, non-"0" string is truthy. The empty string and "0" are falsy.

test t|1|==|1|yes|no
test f|0|==|1|yes|no
say $t $f

Output: yes no
