Compiling and Targets

Implementations

BX is a language specification. A BX program means the same thing whether run by the interpreter, transpiled to C, emitted as assembly, or compiled to a raw binary.

The reference implementation is a C interpreter. It parses commands case-insensitively, splits on |, treats // as comments, skips unknown commands, stores boxes by name (letters, digits, _, -, ?, #), resolves $name and $$name, replaces on reassignment, uses integer math (div-by-zero = 0), seeds premark at load time, mark at runtime (points to next line, re-points on re-run), ignores bad jumps/line numbers, and stops at end.

Transpilation / Compilation Targets

| output | description | |---|---| | C (transpile) | Self-contained C program with embedded runtime; compile with any C99 compiler. | | Assembly (asm) | Assembly + minimal runtime (string storage, box lookup, print, input, math, branch labels). | | Raw binary (raw) | Flat binary, no ELF — for bootloaders or disk images. |

All targets must preserve observable behavior: printed output, input, box values, math results, jumps, termination, errors.

bx compile — Rulesets

bx compile assumes a hosted C toolchain (links libc). For bare-metal, kernels, or bootloaders, a ruleset overrides defaults.

Ruleset format (YAML):

name: freestanding-i386
version: "1.0.0"
description: Bare-metal i386 with explicit link step
cc: i686-linux-gnu-gcc
cflags: -m32 -std=c99 -ffreestanding -nostdlib -nostartfiles -fno-pie -O2 -I.
ld: i686-linux-gnu-ld
ldflags: -m elf_i386 -T kernel.ld
objcopy: i686-linux-gnu-objcopy
suffix: elf

Fields: cc, cflags, ld, ldflags, objcopy, suffix. ld/ldflags optional — without them, cc + cflags does compile+link in one step (common for cross-hosted). suffix = output extension.

Usage:

bx compile program.bx -o program.elf --ruleset freestanding-i386
bx asm program.bx -o program.s --ruleset kernel-i386
bx raw program.bx -o program.bin --ruleset kernel-i386

Search order: $BOXEDLANG_RULESETS → ./rulesets → CWD. First wins (env can shadow).

Shipped rulesets:

  • kernel-i386 — Multiboot1 kernel (used by make kernel).
  • freestanding-i386 — template for bare-metal programs.

Without --ruleset, native target uses cc as usual.

Libraries

Three C libraries in src/, exposed via lib load|NAME:

| library | header | description | |---|---|---| | gfx | bx_gfx.h | UI element tree, themed drawing, framebuffer, vector docs (ui.vg). Colors #rgb..#rrggbbaa. Themes = six ordered tags c h r t x b. make gfx-tests. | | wifi | bx_wifi.h | Scan, connect, status. Native / web / bare-metal paths. lib load|wifi enables high.wifi.*; low.env reports environment. | | snd | bx_snd.h | Software synthesizer (sine/square/saw/tri/noise), voice allocator, WAV export. make snd-tests. |

Performance (reference interpreter, -O3 -march=native)

Interpreter pre-parses to per-line ops, resolves $name without allocation in hot path, inline short box values, caches numeric boxes, flushes stdout only on real TTY.

| benchmark | before opt | after opt | |---|---|---| | 1,000,000-iteration counter (math + jumpif) | 1.18 s | 0.30 s (~0.15 µs/cmd) | | FizzBuzz to 9,999 | 0.043 s | 0.010 s | | box 10k loop | 13 ms | 4 ms | | math 10k loop | 17 ms | 6 ms | | test 10k loop | 18 ms | 4 ms | | jumpif 10k loop | 22 ms | 4 ms | | jump 10k loop | 15 ms | 3 ms | | del 10k loop | 16 ms | 4 ms |
