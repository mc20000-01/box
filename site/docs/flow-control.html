Flow Control

Marks — premark vs mark

BX has two ways to name a location for jumps:

| | premark NAME | mark NAME | |---|---|---| | When it runs | At load time (before any code executes) | At runtime (when the line is reached) | | Name | Literal text from source | Resolved — $boxes and \(boxes) work | | Jump before it exists | Always works | Ignored — jump falls through | | Points to | Its own line (jump falls through) | The line after it | | Re-running | No effect (single entry) | Re-points the name to the new line |

Both kinds share the same marks list; jump NAME|m and jumpif ... NAME|m treat them identically.

premark loop      # exists at line 1
say before loop
mark here         # created when reached
say after mark
jump loop|m       # jumps to line 1 ("premark loop")
jump here|m       # jumps to "say after mark"

jump and jumpif

jump TARGET           # line number (1-based, includes blanks/comments)
jump NAME|m           # mark name (|m required)
jumpif LEFT OP RIGHT TARGET [|m]

If TARGET is not found or out of range, the jump is ignored and execution continues.

Loops

box i|0
premark loop
say $i
math i|$i|1|+
jumpif $i|<|5|loop|m
say done
end

Output: 0 1 2 3 4 done

mark inside a loop

A mark re-points on each pass, so a backward jump lands after the mark:

box tries|0
premark start
mark retry
say attempt $tries
math tries|$tries|1|+
ask try again ?
if $?|==|y|jump|retry|m
say gave up after $tries attempts
end

Mark names built at runtime

mark resolves its name at runtime, so you can generate different marks per iteration:

box id|0
premark build
mark try-$id
say trying $id
math id|$id|1|+
jumpif $id|<|2|build|m

say build finished
ask which try try-1
jump $try-1|m
end

The loop plants try-0 and try-1. The ask writes the user's answer into box try-1, and jump $try-1|m uses that box as the mark name.

end

end stops the program. It is optional — falling off the bottom also ends — but useful to terminate early inside a branch.

Summary table

| command | purpose | |---|---| | premark NAME | load-time label | | mark NAME | runtime label (re-points) | | jump TARGET | unconditional jump (line # or NAME|m) | | jumpif L OP R TARGET | conditional jump | | if L OP R CMD | run one nested command if true | | test OUT L OP R T F | box = T if true else F | | end | stop program |
